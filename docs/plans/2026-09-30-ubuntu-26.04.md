# Ubuntu 26.04 support implementation plan

**Goal:** Allow ordinary ShellReady installation on Ubuntu 26.04, retaining the independent optional-kernel restrictions.

**Architecture:** Extend the explicit platform allowlist. Reuse existing package installation, architecture mapping, and container smoke tests without new dependencies.

**Tech stack:** Bash, Python unittest, GitHub Actions.

1. Add isolated behavioral tests in `tests/test_platform.py` for supported releases and architectures, unsupported systems/architectures, and Ubuntu 26.04 kernel rejection. Run `python3 -m unittest discover -s tests -p test_platform.py -v`; Ubuntu 26.04 acceptance must initially fail.
2. Add `ubuntu:26.04` to `lib/common.sh`, update `README.md`, and add the image to `.github/workflows/ci.yml` for both existing runners.
3. Run platform tests, `python3 -m unittest discover -s tests -v`, `bash tests/check.sh`, and `git diff --check`. Report unavailable local tools separately from failures caused by the change.
4. CI must run `tests/container-smoke.sh` on Ubuntu 26.04 for both architectures. Real SSH interaction and current-kernel BBR require server verification; container tests skip BBR. Leave all changes uncommitted.
