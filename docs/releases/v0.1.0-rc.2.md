# ShellReady v0.1.0-rc.2

本候选版本增加统一的终端字符 Logo，并支持国内镜像下载源码和工具。

## 更新内容

- 安装入口、总菜单和 BBR 子菜单统一使用暖黄色 `slant` 字符 Logo，完整字形为 51 列、6 行。
- 远程安装在下载日志前显示 Logo；经过 sudo 后不重复显示，也不将横幅标记传入后续 Zsh 会话。
- 根据终端空间切换完整或单行简版，保留小窗口数字输入与原方向键导航边界；支持 `NO_COLOR`，重定向输出使用纯文本。
- 新增 `SHELLREADY_DOWNLOAD_MODE=auto|cn|direct`，支持直连优先、国内镜像优先和仅直连模式。
- 支持通过 `SHELLREADY_GITHUB_MIRROR` 指定 HTTPS 下载镜像；已安装的管理入口记住安装时的下载配置，并接受环境变量覆盖。
- 国内模式从源码归档中读取 commit，减少对 GitHub commit API 的依赖；保留工具固定版本与 SHA-256 校验。

## 验证情况

- 本机隔离回归测试 226 项全部通过，无跳过，覆盖菜单重绘、窗口边界、安装、更新、单项管理和 Zsh 会话。
- Bash/Zsh 语法检查和 Git 空白检查通过。
- 本机未安装 ShellCheck，该项未运行。
- Linux 整机安装、真实 SSH 交互、传输及内核启动仍需实机验收，因此继续作为预发布版本。

## 已安装用户更新

运行 `shellready self-update`，或从总菜单选择「更新 ShellReady」。更新后重新运行 `shellready` 查看新版菜单。

在线更新修复已有组件并保留停用状态，不补装已卸载工具，不处理 BBR、内核或登录 Shell 变更。
